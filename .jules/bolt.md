## 2023-10-26 - Resolving N+1 query on Paginated JPA Collections
**Learning:** In Spring Boot applications using Spring Data JPA, retrieving paginated lists of entities that contain mapped `@OneToMany(fetch = FetchType.LAZY)` collections inherently risks an N+1 query problem during DTO mapping (e.g. `orderPage.map(this::toResponse)` calling `order.getItems()`). Using `@EntityGraph` alongside `Pageable` is an anti-pattern as it causes Hibernate to perform in-memory pagination (fetching all records from DB first), which is a severe performance issue.
**Action:** Configure `spring.jpa.properties.hibernate.default_batch_fetch_size=100` globally (or specifically with `@BatchSize`) when paginating entities with nested lazy collections. This allows Hibernate to fetch related collections in a single batch `IN` query, turning O(N) lazy load queries into O(1) without the danger of in-memory pagination.
