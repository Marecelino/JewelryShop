## 2026-11-10 - Spring Data JPA OneToMany Pagination N+1 Optimization
**Learning:** Using `@EntityGraph` to eagerly fetch `OneToMany` relationships during `Page<T>` pagination queries in Spring Data JPA causes a severe performance issue: Hibernate drops database-level pagination (LIMIT/OFFSET) and falls back to in-memory pagination (fetching all records matching the base query into memory, then applying pagination there). This leads to OOM errors and massive memory bloat on large datasets.
**Action:** To resolve N+1 query problems during Spring Data JPA pagination for `OneToMany` collections without ruining database pagination, always use Hibernate's `@BatchSize` annotation on the collection field instead of `@EntityGraph`. This ensures the database query is correctly paginated and collections are fetched efficiently in batches when accessed.
